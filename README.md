# サルベージ・パイロット

Unity / C# で制作している3D宇宙輸送ゲームです。

## 制作で重視したこと

一般的なゲームのようにキーを離すとすぐ停止するのではなく、宇宙空間らしく慣性で進み、逆噴射によって減速・停止する操作感を目標にしています。

移動と減速では、速度を直接書き換えるのではなく力を加える形で制御しています(速度の上限だけは値として制限しています)。

現在も制作中。

## 現在の実装

- 宇宙船の移動・回転
- 慣性を考慮した移動
- 逆噴射による減速・停止
- 破片の回収と運搬
- 目標方向の表示
- 5段階のミッション進行
- 操作練習モード

## 開発環境

- Unity
- C#
